Follow-up tutorial idea: use Python to write your own filesystem manipulation commands (ls, cp, mv, mkdir, etc.) using the stdlib (os, pathlib, shutil). The point is not to replace bash — it is to understand what a shell command actually does by reimplementing it yourself in a language where the primitives are explicit and readable.

Context: the Python Zero-to-One article mentions the REPL can be used as a bash replacement for filesystem operations, but notes that for real use we would write our own commands. This is that follow-up.

Scope:
- pathlib.Path as the core abstraction (not os.path — pathlib is the modern way)
- shutil for copy/move
- argparse or sys.argv for CLI arguments
- Making the script executable with a shebang and installing it into ~/bin
- The bigger point: a shell command is just a program, and you can write one
